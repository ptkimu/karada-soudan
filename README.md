# からだ相談室｜神泉整体センター

悩みを選ぶと、食事・睡眠・運動・姿勢・こころの面からセルフケアのアドバイスを表示し、
「もっと詳しく知りたい」ときは LINE で先生に相談できる Web ページです。

1 つの `index.html` で **HP 版** と **LINE 版（リッチメニュー／LIFF）** の両方に対応しています。
開かれた場所を自動で判別し、相談の送り方だけを切り替えます。

| | HP 版（ブラウザ） | LINE 版（リッチメニュー） |
|---|---|---|
| アドバイス・体操タイマー | ○ | ○ |
| 先生への相談 | 文面をコピー → LINE 公式アカウントを開く | ボタン 1 つでトークに送信 |
| 電話・Web 予約・症状ページへのリンク | ○ | ○ |

## 主な機能

- 15 種類の悩み（体型・からだの不調・睡眠とこころ・姿勢）から複数選択
- 今日の 3 つ（チェックリスト）、カテゴリ別アドバイス、受診の目安
- おすすめ体操 6 種（手順とタイマー付き）
- 公式サイトの症状ページ・スタッフ紹介・Web 予約へのリンク
- 先生への相談フォーム（いつから／どんな時／つらさ 0–10／担当希望 など）

記録や個人情報はサーバーに保存しません。ブラウザに残るのは「選んだ悩み」だけです。

## ファイル構成

```
index.html      アプリ本体（これ 1 枚で動きます）
server.js       ローカル確認用の簡易サーバー（Node.js のみ、依存なし）
docs/SETUP.md   公開・LINE 連携の設定手順
```

## すぐ試す

```bash
node server.js
# → http://localhost:5173
```

または `index.html` をブラウザで直接開いても動きます。

## 設定

`index.html` 内の `CLINIC` を編集します。

| 項目 | 内容 |
|---|---|
| `lineUrl` | LINE 公式アカウントの友だち追加リンク（設定済み） |
| `liffId` | LIFF アプリの ID。設定すると LINE 版でワンタップ送信が有効になります |
| `lineId` | ベーシック ID（`@xxxx`）。HP 版でも文面入りのトークを直接開けます（任意） |
| `tel` / `reserve` / `site` | 電話番号・予約ページ・公式サイト |
| `staff` | 先生の名前・専門・スタッフページのアンカー |
| `pages` | 悩みと公式サイト症状ページの対応 |

公開から LINE リッチメニュー登録までの手順は **[docs/SETUP.md](docs/SETUP.md)** を参照してください。

## ご注意

アドバイスは生活習慣を整えるための一般的な目安で、診断や治療の代わりではありません。
文言を編集するときも「治る」「改善する」などの断定表現は避けてください。
