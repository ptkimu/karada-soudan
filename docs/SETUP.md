# 設定手順書

からだ相談室を公開し、神泉整体センターのホームページと LINE リッチメニューから使えるようにするまでの手順です。

```
① デモ公開（Netlify Drop）……… 5分。まず見た目と動きを確認
② 本番公開 ………………………… 院のサイト or GitHub Pages
③ LIFF アプリ作成 ………………… LINE Developers
④ index.html に LIFF ID を設定
⑤ リッチメニューに登録 ………… LINE Official Account Manager
⑥ ホームページからリンク
⑦ 動作確認
```

---

## ① デモ公開（Netlify Drop）

アカウント登録なしで、フォルダをドラッグするだけで公開できます。

1. ブラウザで <https://app.netlify.com/drop> を開く
2. `index.html` が入ったフォルダ（デスクトップの `karada-soudan-demo`）を画面にドラッグ＆ドロップ
3. 数秒で `https://○○○.netlify.app` の URL が発行される
4. スマホでも開いて確認する

> **注意**
> - ログインせずに公開したサイトは **一定時間（約1時間）で削除** されます。残したい場合は画面の案内に従って Netlify に無料登録し、サイトを「Claim（引き継ぎ）」してください。
> - 登録後は「Site configuration → Change site name」で `shinsen-soudan.netlify.app` のように URL を変えられます。
> - 更新するときは「Deploys」タブに新しいフォルダを再度ドロップします。

デモ URL は、③の LIFF のエンドポイントとしてそのまま使うこともできます（LINE 内での動作テスト用）。

## ② 本番公開

どちらか一つを選びます。

### A. 院のホームページ内に置く（おすすめ）

`https://shibuya-seitai.com/soudan` のように院のドメインで公開できるため、患者さまに一番安心感があります。

公式サイトは Next.js で作られています。サイト管理者に次を依頼してください。

1. このリポジトリの `index.html` を、サイトのプロジェクトの `public/soudan/index.html` に置く
2. デプロイ
3. `https://shibuya-seitai.com/soudan/` で表示されることを確認

> Next.js の `public` フォルダに置いたファイルは、そのまま静的ファイルとして配信されます。
> 末尾スラッシュなしの `/soudan` で開く必要がある場合は、`next.config.js` にリライトを追加してもらってください。

### B. GitHub Pages で公開する（無料）

1. GitHub のリポジトリページ → **Settings** → **Pages**
2. 「Build and deployment」の Source を **Deploy from a branch**
3. Branch を **main**、フォルダを **/(root)** にして **Save**
4. 1〜2分後、`https://ptkimu.github.io/karada-soudan/` で公開される

## ③ LIFF アプリを作成する

LINE の中でこのページを開き、ボタン 1 つで相談内容をトークに送れるようにする設定です。

1. <https://developers.line.biz/console/> に、**LINE 公式アカウントの管理者と同じ LINE アカウント** でログイン
2. **プロバイダー** を選ぶ
   - LINE 公式アカウントで Messaging API を有効にしている場合は、そのとき選んだプロバイダーを使います
   - まだの場合は、LINE Official Account Manager →「設定」→「Messaging API」→「Messaging API を利用する」で、プロバイダーを作成・選択しておきます
3. そのプロバイダーで **「新規チャネル作成」→「LINE ログイン」**
   - チャネル名：`からだ相談室`
   - チャネル説明：`神泉整体センターのセルフケア相談`
   - アプリタイプ：**ウェブアプリ**
   - メールアドレス・プライバシーポリシー URL などを入力して作成
4. 作成したチャネルの **「LIFF」タブ → 「追加」**

   | 項目 | 設定値 |
   |---|---|
   | LIFF アプリ名 | からだ相談室 |
   | サイズ | **Full** |
   | エンドポイント URL | ② で公開した URL（例 `https://shibuya-seitai.com/soudan/`） |
   | Scope | **chat_message.write** と **profile** にチェック |
   | 友だち追加オプション | **On (Aggressive)**（未登録の方に友だち追加を促します） |
   | Scan QR | オフ |

5. 追加すると **LIFF ID**（例 `2001234567-AbCdEfGh`）と **LIFF URL**（`https://liff.line.me/2001234567-AbCdEfGh`）が表示されます
6. チャネルの公開状態が「開発中」の場合は **「公開」** に切り替えます（開発中のままだと、管理者以外は開けません）

> **chat_message.write** がないと、ワンタップ送信ができません。必ずチェックしてください。

## ④ index.html に LIFF ID を設定する

`index.html` の上の方にある `CLINIC` 設定を編集します。

```js
const CLINIC={
  name:"神泉整体センター",
  lineUrl:"https://lin.ee/AfuRTMr",
  lineId:"",                         // 任意：ベーシックID（@xxxx）
  liffId:"2001234567-AbCdEfGh",      // ← ③で発行された LIFF ID を入れる
  ...
```

（任意）`lineId` に LINE 公式アカウントのベーシック ID（`@` から始まる ID）を入れると、HP 版でも「文面が入った状態のトーク画面」を直接開けるようになります。ベーシック ID は LINE Official Account Manager の画面右上、またはアカウント設定で確認できます。

編集したら、② の公開先にもう一度アップロード（デプロイ）します。

## ⑤ リッチメニューに登録する

1. <https://manager.line.biz/> で神泉整体センターのアカウントを開く
2. **「ホーム」→「トークルーム管理」→「リッチメニュー」→「作成」**
3. 表示設定：タイトル（管理用）、表示期間、メニューバーのテキスト（例「メニュー」）
4. コンテンツ設定：テンプレートを選び、画像をアップロード
   - 画像サイズの例：2500×1686（大）／2500×843（小）
5. 「からだ相談」にしたいエリアのアクションを設定

   | 項目 | 設定値 |
   |---|---|
   | タイプ | **リンク** |
   | URL | `https://liff.line.me/（LIFF ID）` |
   | アクションラベル | からだ相談 |

6. 保存して、表示期間内であることを確認

> URL は必ず **`https://liff.line.me/...`** の形にしてください。エンドポイント URL を直接入れると LINE 版として動かず、ワンタップ送信ができません。

| からだ相談 | Web 予約 | 料金・メニュー |
|---|---|---|
| **アクセス** | **スタッフ紹介** | **電話する** |

- 料金・メニュー：`https://shibuya-seitai.com/menu`
- アクセス：`https://shibuya-seitai.com/access`
- スタッフ紹介：`https://shibuya-seitai.com/staff`
- 電話する：`tel:0354890425`

## ⑥ ホームページからリンクする

HP 版は ② の URL をそのままリンクします。例：

```html
<a href="/soudan/">セルフケア相談（悩みを選ぶだけ）</a>
```

置き場所の例：トップページのボタン、症状ページの最後、「初めての方へ」ページ。

## ⑦ 動作確認チェックリスト

**HP 版（スマホとパソコンのブラウザ）**
- [ ] 悩みを選ぶとアドバイス・体操・受診の目安が表示される
- [ ] 体操のタイマーが動く
- [ ] 「神泉整体センターの解説」から症状ページが開く
- [ ] 「LINEで先生に送る」→ 文面がコピーされ、LINE 公式アカウントが開く
- [ ] 「電話で相談する」でスマホの発信画面になる
- [ ] 「Webで予約する」で予約ページが開く

**LINE 版（スマホの LINE アプリ）**
- [ ] リッチメニューの「からだ相談」でページが LINE 内に開く
- [ ] ボタンの表示が「この内容を先生に送る」になっている
- [ ] 押すとトークに相談文が送信され、画面が閉じる
- [ ] 院側の LINE チャット画面で相談文が届いている

うまくいかないとき：

| 症状 | 確認すること |
|---|---|
| ボタンが「LINEで先生に送る」のまま | リッチメニューの URL が `https://liff.line.me/...` か／`liffId` が正しいか |
| 送信に失敗する | LIFF の Scope に `chat_message.write` があるか／トーク画面から開いたか |
| 管理者以外が開けない | LINE ログインチャネルが「公開」になっているか |
| 画面が真っ白 | エンドポイント URL が ② の公開 URL と完全に一致しているか（末尾 `/` を含む） |

## 内容を編集するには

`index.html` の `<script>` 内にあるデータを書き換えます。

| データ | 内容 |
|---|---|
| `GROUPS` | 悩みのグループ分けと並び順 |
| `ADV` | 悩みごとのアドバイス（`food` / `sleep` / `move` / `posture` / `mind`）、おすすめ体操 `r`、受診の目安 `red` |
| `ROUTINES` | 体操の名前・時間・手順 |
| `CLINIC.pages` | 悩みと公式サイト症状ページの対応 |

> 表現の注意：「治る」「改善します」などの断定は避け、「〜がおすすめです」「〜の目安です」としてください。
